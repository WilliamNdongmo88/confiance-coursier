20 choses à faire avant de mettre ton site vibecodé en ligne
( en moins de 35 sec)

La liste numérotée :

1. Limite le nombre de requêtes par visiteur

2. plafonne les appels API

3. plafonne tes dépenses chez les fournisseurs ####################

4. Affiche un message quand ça plante

5. Affiche un chargement a lieu d'une page blanche ################

6. Prévois le cas ou il n'y a rien afficher

7. Gère les requêtes qui échouent

8. Gère les APIs qui ne répondent pas

9. Empêche le double clic sur "envoyer" ou tout autre bouton de soumission

10. Empêche le double paiement

11. Charge que les données que tu affiches

12. Ajoute des index pour accélérer les recherches

13. Découpe les longues listes en page

14. Compresse les fichiers envoyé

15. Limite le poids des fichiers envoyés

16. Garde en mémoire ce qui ne change pas

17. Je veux être alerté si mon site tombe

18. Garde une trace de chaque erreur

19. Teste avec plusieurs visiteurs en meme temps

20. Vérifie que ta sauvegarde se restaure.
